1. 文書の目的
本書は「パチンコ・スロット データ収集・分析プラットフォーム（通称: P店データリサーチ）」を、本番運用エージェント Hermes により自動運用する形で構築するための要件を定義する。開発支援AIである Claude Code を用いて実装し、Hermes が日次運用を担う前提で、機能要件・非機能要件・制約・受け入れ基準を明確化する。
2. 背景と課題
パチンコ・スロット店舗の公開データ（差枚・ゲーム数・確率等）は日々更新されるが、手作業での収集・集計は工数が大きく、分析の即時性・網羅性に欠ける。営業分析・配分分析・店舗傾向分析を効率化するため、公開データを日次で自動収集し、機種別・台番別・店舗別に分析し、翌営業日に自動レポート配信する仕組みが求められている。
3. システム目的
許諾済みの公開データサイト（みんレポ等）から日次でデータを自動収集する。
収集データを機種別・台番別・店舗別に分析し、差枚・勝率・注目機種等の指標を算出する。
分析結果を自動でレポート化し、Chatwork / Slack 等へ翌日配信する。
Web画面からエリア（都道府県）を起点に店舗を選び、その場でリサーチできる。
Hermes Agent が日次運用・リトライ・監視・障害通知を一元的に司る。

5. スコープ
5.1 対象範囲（In Scope）
みんレポからのスロット台データ収集（店舗単位・台番単位）。
基本分析（店舗別/機種別/台番別の総差枚・平均差枚・平均G数・勝率・プラス台割合）。
Web UI でのエリア選択 → 店舗一覧 → オンデマンドリサーチ。
日次レポートのCSV/テキスト生成と配信。
Hermes による日次オーケストレーション（収集→分析→配信→ログ→通知）。
5.2 対象外（Out of Scope）— 将来フェーズ
高度分析（配分・並び・塊・末尾・島分析、高設定推定、異常検知）はPhase2/3で対応。
パチンコ（玉）データ、複数媒体横断、API公開、モバイルアプリ、LINE Bot。
Hermes のLLMエージェント化（自律判断）は将来拡張とする。

9. 制約条件
取得対象は許諾済みの公開データサイトに限定する。
CAPTCHA突破・アクセス制限回避・匿名化による回避取得・大量アクセスは禁止する。
取得先ホストはホワイトリストで固定し、任意URLへのアクセスは許可しない。
Claude Code は開発支援に用い、本番常駐処理は行わない。本番運用はHermesが担う。
10. 受け入れ基準
都道府県を選択すると当該エリアの店舗一覧が表示され、店舗を選ぶとリサーチ結果が表示される。
Hermes日次フローを起動すると、全アクティブ店舗の収集→分析→配信が実行され、実行履歴が記録される。
収集・分析の再実行で重複データが発生しない。
不正ホストURL・認証なしの操作系API呼び出しが拒否される。
失敗発生時に管理者へアラートが届く（チャンネル設定時）。
